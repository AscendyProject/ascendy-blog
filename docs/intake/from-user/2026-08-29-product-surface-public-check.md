> 서비스 블로그 §9(개정) 이 요구하는 **도착지 서술**("링크를 누르면 무엇이 되는지")의
> 근거다. 여기 적힌 것은 **공개 웹페이지에서 누구나 볼 수 있는 내용**과, 운영자가 공개를
> 승인한 진술(§1-b) 뿐이다. 비공개 저장소나 내부 문서에서 가져온 내용은 넣지 않는다 —
> **이 파일도 공개된다.**
>
> 랜딩 문구는 **제품이 스스로 공개적으로 내세우는 주장**이다. 실제 동작의 품질까지 이
> 문서가 보증하지는 않는다 — 실동작 확인은 별도 진행 중이고, 확인 전인 항목은 §3에
> 분리해 두었다.

## 1. 확인한 것 (2026-08-29, 공개 페이지)

**한국어 랜딩** — 영어 랜딩과 별개로 **완전한 한국어 페이지가 존재**한다.

- 헤드라인: "너와 나의 소셜 클라우드", "한 번의 요청, 끝까지"
- 가입 버튼: **"무료로 시작하기"** (활성)
- 요금제 섹션: "간단하고 투명한 요금제" — Free 플랜 이용 가능, 상위 두 플랜은 **"출시 예정"**
- 상위 플랜에는 "출시 알림 받기"

**영어 랜딩**

- 헤드라인: "AI Photo Agent for Couples & Families", "You & Me, Social Cloud",
  "Find any moment by simply talking to it"
- 설명: "Ascendy is the AI photo cloud built for shared memories",
  **"Search, organize into an album, and share to a Group — all in one natural-language request"**
- 버튼: "Get Started Free", "Sign In", "Notify me at launch"

**가입 화면** (`/signup`)

버튼 라벨만으로는 가입 가능 여부를 알 수 없어 가입 화면까지 직접 열어 확인했다.

- 입력 필드: Display Name / Email / Password / Confirm Password
- **초대 코드는 선택 항목이다** ("Invite Code (optional)") — 초대 없이도 폼을 제출할 수 있는
  구성이다
- 필수 동의: 만 14세 이상, 이용약관, 개인정보처리방침
- 액션 버튼: "Create account", reCAPTCHA 적용

**확인 범위의 한계:** 여기까지가 관찰이다. **실제로 계정 생성을 끝까지 진행해 보지는
않았다** — 운영자의 서비스에 테스트 계정을 만드는 것이 적절하지 않다고 판단했다. 따라서
"가입이 반드시 성공한다"는 서술은 하지 않고, 글에는 **관찰된 것**(이메일로 가입하는 폼이
제공되고, 요금제에 무료 플랜이 있다)까지만 쓴다.

**공통**

- **앱 스토어 / 플레이스토어 링크가 없다.** 모바일 앱 다운로드 경로 없음
- 웹에서 동작

## 1-b. 운영자 진술 (2026-08-29)

랜딩 관찰과 별개로, 운영자가 직접 확인해 준 것:

> 현재 이용 경로는 **웹**이다. 모바일 앱은 **아직 출시되지 않았다.**

"앱은 아직 없습니다"라는 글의 서술은 랜딩의 스토어 링크 부재가 아니라 **이 진술**에
근거한다. (랜딩에 스토어 링크가 없다는 관찰만으로는 앱의 부재가 증명되지 않는다 —
별도 배포·베타·지역 한정 배포의 가능성이 남기 때문이다.)

출시 시점이나 개발 상태는 미발표 로드맵이므로 이 문서에도, 글에도 적지 않는다.

## 2. 이 기록이 뒷받침하는 글의 서술

- "웹에서 쓴다 / 이메일로 가입한다 / 무료 플랜이 있다" → §1 가입 화면 및 요금제 섹션
  관찰에 근거. **"가입이 열려 있다", "바로 시작할 수 있다"처럼 결과를 보장하는 표현은
  쓰지 않는다** (계정 생성을 끝까지 확인하지 않았다)
- "앱은 아직 없다" → **§1-b 운영자 진술**에 근거 (랜딩 관찰이 아니다)
- 한국어 글의 링크를 한국어 랜딩으로 보내는 것 → §1 한국어 페이지 존재 확인에 근거

**제품 동작 서술은 이 문서가 아니라 2026-08-18 인테이크(운영자 1인칭)에 근거한다** —
"시간·장소·인물로 정리된다", "말로 요청받는 쪽으로 방향을 바꿨다"까지가 그 범위다.
랜딩 카피에만 있는 기능 열거는 **글에 쓰지 않았다.**

## 3. 확인하지 않아 글에 쓰지 않은 것

여기 적는 것은 **이 확인 작업의 한계**이지, 제품에 무엇이 있고 없는지가 아니다.

- **랜딩 문구는 제품이 스스로 내세우는 공개 주장**이지 실동작 확인이 아니다. 그래서 글의
  제품 동작 서술은 랜딩이 아니라 **2026-08-18 인테이크(운영자 1인칭)가 뒷받침하는 범위**로
  제한했다 — "시간·장소·인물로 정리된다", "말로 요청받는 쪽으로 방향을 바꿨다"까지.
- **계정 생성이 끝까지 완료되는지**는 확인하지 않았다(§1 가입 화면 참조). 지역 제한이나
  승인 대기가 있는지도 모른다. 그래서 "가입이 열려 있다"가 아니라 "이메일로 가입하는 폼이
  있다"까지만 썼다.
- 글의 **"아직 다 되지는 않는다"**는 이번 개정 이전부터 발행본에 있던 문장이며, 그대로
  두었다. 이 문서는 제품의 현재 한계에 대해 **아무것도 새로 주장하지 않는다** — 어떤 요청이
  더 어렵다거나 무엇이 아직 안 된다는 서술은 근거가 없으므로 글에도 넣지 않았다.

## 4. 유효기간 주의

랜딩 문구·요금제·가입 개방 여부는 **바뀔 수 있다.** 위 서술은 2026-08-29 시점 확인이며,
글의 CTA를 다시 손볼 때는 이 문서부터 갱신한다. 특히 **앱이 출시되면** "앱은 아직 없습니다"가
들어간 글 3편을 모두 고쳐야 한다.
