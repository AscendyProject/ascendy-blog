## 핵심 주장 (인터뷰에서 도출)

1. **'보고를 위한 보고'는 죽어야 한다.** 보고서를 *더 잘 쓰려고* 허비하는 시간·인력, 심지어
   그걸 잘하려 AI를 쓰는 건 — *잘못된 곳에 AI를 쓰는 토큰 낭비*다.
2. **보고(push)는 정보공유의 비효율 형태.** 보고의 진짜 비용은 *받는 사람 입맛에 맞춰 가공하는
   노동*이고, 그게 관료제 시간의 큰 덩어리다.
3. **대안은 pull + 에이전트 가공 레이어.** 인간은 raw 데이터(맥락째)를 지식 베이스에 계속 넣고,
   *에이전트가 가공·정리·검색 가능하게* 만든다. 필요한 사람이 원하는 형식으로 가져간다.
   "쌓아두면 쓰레기"라는 pull의 함정은 *정리하는 사람*이 아니라 *정리하는 에이전트*가 해결한다.
4. **관료제 재편.** 대기업은 무조건 비효율이라 작은 업무 단위로 쪼개져야. 보고·조정·결재 계층
   상당수가 에이전트 레이어로 대체.
5. **AI 못 쓰는 사람 = 도태 (강한 주장 + 단서).** 컴퓨터 못 쓰는 사람이 사무직 안 되듯. *안타깝
   지만*이라는 인간적 단서 + 1인칭 베팅으로(사람 비난 아닌 구조적 관찰).
6. **대기업은 사라지지 않는다.** 강한 영역(자본·규모·전문가+AI)엔 남고, *약한 분야*는 AI 레버리지
   작은 기업이 가져간다. 1인이 안 되는 전문영역(브랜딩·마케팅·디자인)은 '전문가+AI'가 나으니
   '다 1인 된다'는 순진. 미래 = 강점만 남은 대기업 ↔ 고레버리지 작은 셀들.
